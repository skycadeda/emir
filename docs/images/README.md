# Figures

Every image here and in `blog/images/` is made by one script from runs of this
repository; none is drawn by hand. Regenerate them all with

```sh
python scripts/make_figures.py            # about a minute
python scripts/make_figures.py --only accuracy,scaling
```

This file is generated by the same script (`--check` compares it).

Every figure is drawn with matplotlib 3.11.2 (`MATPLOTLIB` in the script;
another version lays text out differently, so the script refuses it).

Conventions: `<name>.png` is the light variant and `<name>_dark.png` the dark one
(the hero banner is the exception: `hero.png` is dark, `hero_light.png` light). In
Markdown that renders on GitHub, pick by the reader's theme:

```html
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="docs/images/accuracy_dark.png">
  <img alt="..." src="docs/images/accuracy.png">
</picture>
```

Every figure that shows results says so: **Screening, not sign-off.** Numbers from the Xyce sweep
carry the label "Xyce, synthetic, serial".

## The waveform self-consistent loop against RCC, pass by pass (rms, peak, residual, what remains)

Files: `docs/images/selfconsist_waveform.png`, `docs/images/selfconsist_waveform_dark.png`

Source: examples/06_big_block/results/selfconsist_waveform.csv (Xyce, synthetic, serial), made by examples/06_big_block/selfconsist.py.

Alt text: Three charts. Against the pass, the governing branch's peak and rms error fall from up to 70 % to within 1 % of RCC by pass 2 on the 32-inverter meshes, and at 4.1 % droop to within 2 % from pass 3 on (0.78 % at the reported pass, 7); the residual falls under its tolerance after 4 or 5 simulations, and at 4.1 % droop levels off at about 1.3 times it, where the answer no longer moves, while the plain update grows and is stopped; at the reported pass, the minor branches' peak error widens with the grid against RCC and stays within about 1 % against RCC without the grid's capacitors.

Caption: What feeding each pin its droop waveform does on switching inverters (Xyce, synthetic, serial): rms and peak come to within about 1 % of RCC on the governing branch; what remains is the grid's own capacitance.

Regenerate: `python scripts/make_figures.py --only selfconsist_waveform`
